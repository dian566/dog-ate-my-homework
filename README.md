One line from a dog that followed the teacher's instruction far too
literally, made for the [make.fun bounty](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c)
"The Dog Ate My Homework: Funniest Excuse" — $2 pot, top 8 paid, 1st place $0.64.

## The excuse

> Your homework said it needed to be 'turned in' — so I turned it in. To my stomach. It never specified where.

110 characters on one line. The dog read the instruction, did exactly what
it said, and is genuinely confused about why anyone is upset. The joke
lands on the literal reading: "turned in" never named a destination, so
the stomach counted as one.

## Running it

`main.py` drops that exact line into `/output/entry.txt`. Every run
produces the same bytes — nothing random, nothing time-based.

```sh
python3 main.py
cat /output/entry.txt
```
