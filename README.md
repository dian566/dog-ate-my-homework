A one-line excuse from a dog caught eating the homework, written for the
[make.fun bounty](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c)
"The Dog Ate My Homework: Funniest Excuse" ($2 pot, top 8 paid, 1st place $0.64).

## The entry

> Your homework said it needed to be 'turned in' — so I turned it in. To my stomach. It never specified where.

110 characters, one line. The dog took the instruction literally and believes
it has done nothing wrong.

## How it works

`main.py` writes that exact line to `/output/entry.txt`. The output is
deterministic: the same bytes on every run, no randomness, no clock.

```sh
python3 main.py
cat /output/entry.txt
```
